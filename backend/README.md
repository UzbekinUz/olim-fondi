# Olim Foundation — backend

Express 5 + MongoDB.

```
npm install
npm run dev      # nodemon app
npm start
```

`.env` (git'ga qo'shilmaydi):

- `DB_CONNECTION_STRING` — MongoDB manzili
- `APP_PORT` — port (berilmasa 5000)
- `JWT_SECRET` — admin va stipendiat tokenlari uchun
- `JWT_USER_SECRET` — foydalanuvchi tokenlari uchun
